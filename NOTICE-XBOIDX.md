InstaTube Toolkit by Xboy Rex is a modified fork of InstaDownload by Orang-Studio. Copyright and license notices in upstream files are retained. The project is distributed under GNU GPL v3; see `LICENSE`.

This fork includes a reworked Jetpack Compose interface, Xboy Rex branding, a custom launcher icon, an isolated Caption Studio, local Library history, and a public YouTube metadata preview through oEmbed. It retains the upstream Instagram public-media parser and storage code.
